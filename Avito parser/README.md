# Бот скупки iPhone на Авито с уведомлениями в Telegram

Раз в минуту бот смотрит новые объявления о продаже iPhone в Москве, отсеивает
запчасти, магазины и продавцов без отзывов и сравнивает цену с вашей таблицей
цен скупки. Дальше он:

| Цена объявления | Что делает бот |
|---|---|
| 🔥 не выше цены скупки | пишет продавцу сам и соглашается на его цену |
| ✅ до +25% к цене скупки | пишет продавцу сам и предлагает вашу цену скупки |
| 👀 от +25% до +40% | только присылает вам карточку с кнопкой «Написать продавцу» |
| дороже +40% | пропускает |

Сам бот пишет только с 9:00 до 22:00 и не больше 30 сообщений в сутки.
Ответы продавцов он пересылает вам в Telegram. Если продавец согласен, вы
получите отдельное заметное сообщение 🟢 **СДЕЛКА**. Отвечать продавцу можно
прямо из Telegram.

Бот работает на вашем Mac, пока Mac включён и не спит.

---

## ⚠️ Прочитайте до начала

1. **Правила Авито запрещают автоматический доступ и массовые рассылки.**
   Аккаунт, с которого работает бот, могут ограничить или заблокировать.
   Поэтому **заведите для бота отдельный аккаунт Авито** и не используйте свой
   основной. Лимиты в боте (30 сообщений в сутки, паузы 30–120 секунд)
   выбраны осторожно, не увеличивайте их сильно.
2. **Авито время от времени меняет вёрстку сайта.** Тогда бот перестаёт видеть
   объявления и пишет вам «Похоже, Авито изменил вёрстку». Все адреса
   элементов страницы собраны в одном файле `bot/avito/selectors.py`
   (подробнее в разделе «Если Авито изменил сайт»).
3. **Бот работает, только пока Mac включён и не спит.** MacBook с закрытой
   крышкой без внешнего монитора засыпает, и бот останавливается.
4. **Капчу бот не обходит.** Если Авито попросит капчу или вход, бот встанет на
   паузу и напишет вам. Пройдите капчу в окне браузера на Mac, и бот продолжит
   работу сам.
5. Первые сутки бот работает в **пробном режиме (DRY RUN)**: всё делает, но
   продавцам не пишет, а только присылает вам «[DRY RUN] написал бы…».

## Что понадобится

- Mac с macOS 12 или новее и интернет (VPN лучше выключить, см. раздел «Если что-то не работает»);
- 30–60 минут на первую настройку;
- Telegram на телефоне;
- отдельный аккаунт Авито для бота;
- аккаунт Google для таблицы цен. Можно пропустить и сначала проверить бота на
  ценах из файла `prices_example.csv`.

> **Как открыть Терминал.** Нажмите `⌘ Cmd + Пробел`, наберите «Терминал»
> и нажмите Enter. Откроется окно, куда вводятся команды. Команду из этой
> инструкции скопируйте, вставьте в Терминал (`⌘ Cmd + V`) и нажмите Enter.
> Каждую команду вводите отдельно.

## Шаг 1. Переложите папку проекта в домашнюю папку

macOS не разрешает автозапуску работать с файлами в папках «Документы»,
«Рабочий стол» и «Загрузки». Поэтому папку проекта нужно переложить.

1. Откройте Finder и найдите папку проекта (сейчас она называется `Avito parser`).
2. Переименуйте её в `avito-iphone-bot`: выделите папку, нажмите Enter, введите новое имя и снова нажмите Enter.
3. В Finder откройте меню **Переход → Личное** (или нажмите `⌘ Cmd + Shift + H`).
   Откроется ваша домашняя папка, в ней лежат «Документы», «Загрузки» и т. д.
4. Перетащите папку `avito-iphone-bot` в домашнюю папку. Если Finder её
   скопировал, а не переместил, старую копию удалите.

В итоге путь к проекту должен быть `~/avito-iphone-bot`. Проверьте в Терминале:

```bash
ls ~/avito-iphone-bot
```

Должен появиться список файлов: `README.md  bot  config.yaml  main.py …`

## Шаг 2. Установите Python 3.12

1. Откройте https://www.python.org/downloads/macos/
2. Найдите последнюю версию **Python 3.12.x** и скачайте
   **«macOS 64-bit universal2 installer»** (файл `.pkg`).
3. Откройте скачанный файл и нажимайте «Продолжить», пока установка не закончится.
4. В конце откроется папка «Python 3.12». Дважды щёлкните в ней по файлу
   **`Install Certificates.command`**: откроется окно Терминала, дождитесь
   надписи `[Process completed]` и закройте его. Без этого Python не сможет
   безопасно подключаться к Telegram и Google.
   Если папка не открылась сама: Finder → Программы → Python 3.12.

Проверьте в Терминале (откройте новое окно Терминала):

```bash
python3.12 --version
```

Должно появиться `Python 3.12.…`. Если Терминал пишет `command not found`,
закройте Терминал полностью (`⌘ Cmd + Q`), откройте его снова и повторите.

## Шаг 3. Установите бота

В Терминале выполните по очереди:

```bash
cd ~/avito-iphone-bot
```

```bash
chmod +x scripts/*.sh start.command
```

```bash
./scripts/setup.sh
```

Установка займёт 2–5 минут: скачиваются библиотеки и браузер Chromium
(~150 МБ). В конце появится `✅ Установка завершена.` и в папке будет создан

> **Как открыть файл `.env`.** Его имя начинается с точки, поэтому Finder его
> не показывает. Открыть файл в TextEdit можно командой:
>
> ```bash
> open -e ~/avito-iphone-bot/.env
> ```
>
> Или в Finder нажмите `⌘ Cmd + Shift + .` (точка), и скрытые файлы появятся.
> Значения пишите сразу после `=`, без кавычек и пробелов.
> Сохранить: `⌘ Cmd + S`.

## Шаг 4. Создайте Telegram-бота

1. В Telegram найдите **@BotFather** (у настоящего синяя галочка) и нажмите «Запустить» / Start.
2. Отправьте ему команду `/newbot`.
3. Он попросит имя бота. Напишите любое, например `Скупка iPhone`.
4. Потом он попросит «username»: латиница, в конце обязательно `bot`,
   например `skupka_iphone_2216_bot`. Если имя занято, придумайте другое.
5. BotFather пришлёт **токен**: длинную строку вида
   `7123456789:AAH4kZ...`. Это пароль от вашего бота, никому его не показывайте.
6. Откройте файл `.env` (см. выше) и вставьте токен:
   ```
   TELEGRAM_BOT_TOKEN=7123456789:AAH4kZ...
   ```
   Сохраните файл.

## Шаг 5. Узнайте свой chat_id

Бот отвечает только вам, и для этого ему нужен номер вашего чата.

1. В Telegram откройте своего нового бота (ссылка была в сообщении BotFather),
   нажмите «Запустить» и напишите ему любое слово, например `привет`.
2. В Терминале:
   ```bash
   cd ~/avito-iphone-bot
   ```
   ```bash
   ./venv/bin/python scripts/get_chat_id.py
   ```
3. Появится строка `chat_id: 123456789`. Впишите это число в `.env`:
   ```
   TELEGRAM_CHAT_ID=123456789
   ```
   Сохраните файл.

## Шаг 6. Подключите Google Таблицу с ценами

> Этот шаг можно отложить. Пока `GOOGLE_SHEET_ID` в `.env` пустой, бот берёт цены
> из файла `prices_example.csv` в папке проекта (цены там примерные, для проверки).

### 6.1. Создайте таблицу

Создайте Google Таблицу (https://sheets.new). Первая строка — заголовки
**ровно** такие:

| Модель | Память | Цена скупки | Средняя цена на рынке | Цена продажи | Чистая прибыль |
|---|---|---|---|---|---|
| iPhone 15 Pro | 256 | 58000 | 66000 | 67000 | 9000 |
| iPhone 16 Pro Max | 1 ТБ | 100000 | 115000 | 116000 | 16000 |

- **Модель** — как в примере: `iPhone 13 mini`, `iPhone 14 Plus`, `iPhone 15 Pro Max`.
  Бот ищет в объявлениях только модели, которые есть в таблице. Новую модель
  (например, iPhone 17 Pro) достаточно добавить строкой в таблицу.
- **Память** — `128`, `256`, `512` или `1 ТБ`.
- **Цены** — просто числа. Пробелы и знак ₽ не мешают.
- Для каждого объёма памяти нужна своя строка.

### 6.2. Создайте сервисный аккаунт Google

Это «робот» Google, через которого бот читает вашу таблицу.

1. Откройте https://console.cloud.google.com/ и войдите в свой Google-аккаунт.
   Если появится окно с условиями, примите их.
2. Вверху слева нажмите на выбор проекта → **«Новый проект»** (New Project).
   Назовите его `avito-bot` и нажмите **«Создать»**. Дождитесь уведомления и
   выберите этот проект вверху.
3. Включите два API:
   - откройте https://console.cloud.google.com/apis/library/sheets.googleapis.com и нажмите **«Включить»** (Enable);
   - откройте https://console.cloud.google.com/apis/library/drive.googleapis.com и тоже нажмите **«Включить»**.
4. Откройте https://console.cloud.google.com/iam-admin/serviceaccounts и нажмите
   **«Создать сервисный аккаунт»** (Create service account).
   Имя: `avito-bot`. Нажмите «Создать и продолжить», затем «Готово».
   Роль выбирать не нужно.
5. В списке нажмите на созданный аккаунт → вкладка **«Ключи»** (Keys) →
   **«Добавить ключ» → «Создать новый ключ»** → тип **JSON** → «Создать».
   Скачается файл с длинным названием `avito-bot-xxxxxx.json`.
6. Переименуйте этот файл в **`google_service_account.json`** и положите его в
   папку `~/avito-iphone-bot/credentials/`.

### 6.3. Дайте сервисному аккаунту доступ к таблице

1. Откройте скачанный JSON-файл в TextEdit и найдите строку `"client_email"`.
   Адрес выглядит так: `avito-bot@avito-bot-123456.iam.gserviceaccount.com`.
   Скопируйте его без кавычек.
2. В Google Таблице нажмите **«Настройки доступа»** (Share), вставьте этот
   адрес, выберите роль **«Читатель»**, снимите галочку «Уведомить» и нажмите «Отправить».

### 6.4. Впишите ID таблицы в `.env`

ID таблицы — это кусок адреса между `/d/` и `/edit`:

```
https://docs.google.com/spreadsheets/d/1AbCdEf_ВОТ_ЭТО_И_ЕСТЬ_ID_xyz/edit#gid=0
```

В `.env`:

```
GOOGLE_SHEET_ID=1AbCdEf_ВОТ_ЭТО_И_ЕСТЬ_ID_xyz
GOOGLE_SHEET_WORKSHEET=Лист1
```

`GOOGLE_SHEET_WORKSHEET` — название вкладки внизу таблицы (обычно «Лист1»).
Если оставить его пустым, бот возьмёт первую вкладку.

Бот перечитывает таблицу каждые 5 минут, так что цены можно менять на ходу.

## Шаг 10. Первый запуск (пробный режим DRY RUN)

```bash
./scripts/run.sh
```

Можно и без Терминала: дважды щёлкните по файлу **`start.command`** в папке проекта.
Если macOS спросит, открыть ли его, нажмите «Открыть».

Что произойдёт:

1. Откроется окно браузера с Авито. **Не закрывайте его**: через него бот работает.
   Свернуть окно можно.
2. В Telegram придёт «🤖 Бот запущен, 🧪 режим DRY RUN».
3. Через минуту придёт «👋 Первый запуск: N текущих объявлений помечены как
   просмотренные». Старые объявления бот пропускает, чтобы не засыпать вас ими.
4. Дальше начнут приходить новые подходящие объявления:
   - `[DRY RUN] ✅ iPhone 15 Pro 256 ГБ — написал бы продавцу` — тут бот в боевом режиме написал бы сам;
   - `👀 … — можно предложить` — тут решаете вы.

Остановить бота: в окне Терминала нажмите `Ctrl + C` (или закройте это окно).

**Оставьте бота в пробном режиме хотя бы на сутки.** Проверьте, что модели
определяются правильно, лишнее отсеивается, а предложенные цены вас устраивают.

## Шаг 11. Автозапуск (бот сам стартует после перезагрузки Mac)

Сначала остановите бота, если он запущен вручную (`Ctrl + C`). Затем:

```bash
cd ~/avito-iphone-bot
```

```bash
./scripts/install_autostart.sh
```

После этого бот:
- запускается сразу и при каждом входе в macOS;
- перезапускается сам, если упал;
- не даёт Mac уснуть, пока работает (через `caffeinate`).

**Чтобы бот стартовал после перезагрузки без вас:**
- **Системные настройки → Пользователи и группы → Автоматический вход** —
  выберите своего пользователя. Если пункт недоступен, у вас включён FileVault;
  тогда после перезагрузки нужно один раз ввести пароль.
- **Системные настройки → Аккумулятор (или «Экономия энергии») → Параметры** —
  включите «Не переводить в режим сна автоматически, когда дисплей выключен»
  (при питании от сети).
- MacBook держите на зарядке и **не закрывайте крышку** (или подключите внешний монитор).

Полезные команды:

| Что сделать | Команда |
|---|---|
| Выключить автозапуск и остановить бота | `./scripts/uninstall_autostart.sh` |
| Перезапустить бота (например, после правки `.env`) | `./scripts/restart.sh` |
| Посмотреть, что бот делает прямо сейчас | `tail -f logs/bot.log` (выход — `Ctrl + C`) |

## Шаг 12. Боевой режим

Когда пробный режим вас устроил:

1. Откройте `config.yaml` (в папке проекта, двойной щелчок → TextEdit).
2. Замените `dry_run: true` на `dry_run: false` и сохраните.
3. Отправьте боту в Telegram команду `/reload`.

С этого момента бот реально пишет продавцам. Вернуть пробный режим:
`dry_run: true` и снова `/reload`.

## Как пользоваться каждый день

### Команды в Telegram

| Команда | Что делает |
|---|---|
| `/status` | работает или на паузе, когда была последняя проверка, сколько отправлено сегодня (X/30) |
| `/pause`, `/resume` | поставить бота на паузу и продолжить |
| `/autowrite_off`, `/autowrite_on` | выключить или включить только автописьма (уведомления продолжат приходить) |
| `/stats` | статистика за сегодня и за 7 дней: найдено, отсеяно (по причинам), написано, ответили, согласились |
| `/deals` | диалоги, где продавец согласился (🟢) или торгуется (💸) |
| `/reload` | перечитать таблицу цен и `config.yaml` |
| `/cancel` | отменить ввод текста продавцу |

### Уведомления

- **✅ / 🔥 … — написал продавцу** — бот сам отправил предложение. Под сообщением кнопки «Открыть на Авито» и «Ответить продавцу».
- **👀 … — можно предложить** — бот не писал. В конце указана причина: дорого (+25–40%), ночь, дневной лимит, автописьма выключены или продавцу уже писали. Кнопка **«Написать продавцу»** спросит: отправить шаблон с вашей ценой или свой текст.
- **💬 Ответ по …** — продавец ответил. Если он назвал сумму, бот выделит её и покажет ваш максимум (скупка +25%). Бот **сам не торгуется**.
- **🟢🟢🟢 СДЕЛКА** — продавец согласен.
- **⚠️ Авито просит капчу/вход** — подойдите к Mac, пройдите капчу в окне браузера и нажмите «Продолжить». Бот и сам проверяет капчу каждые 30 секунд, а пока пауза не снята, напоминает раз в 30 минут.

### Как ответить продавцу из Telegram

- Нажмите **«Ответить продавцу»** под уведомлением и напишите текст следующим сообщением, **или**
- сделайте **reply** (свайп влево по сообщению или «Ответить») на любое уведомление по объявлению и напишите текст.

Бот отправит текст в чат на Авито и подтвердит «✉️ Отправлено». Между
отправками он держит паузу 30–120 секунд, поэтому иногда ответ уходит через
минуту-две. Отправка из Telegram работает в любое время суток и в дневной
лимит не входит.

## Основные настройки (`config.yaml`)

Все параметры описаны прямо в файле. После правки отправьте `/reload`.

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `dry_run` | `true` | пробный режим: продавцам не пишет |
| `search.search_url` | Москва, iPhone, сначала новые, только частные | ссылка на поиск. Можно настроить фильтры на сайте Авито и вставить свою ссылку |
| `search.check_interval_sec` | `60` | как часто проверять новые объявления |
| `filters.stop_words` | список | слова, по которым отсеиваются запчасти и неисправные |
| `filters.stop_word_exceptions` | список | фразы, которые не считаются стоп-словами («icloud чистый», «без ремонта») |
| `filters.shop_words` | список | слова магазинов и перекупов |
| `filters.max_seller_active_listings` | `5` | у продавца больше объявлений — значит, перекуп |
| `filters.min_sane_price` | `5000` | цена ниже — отсев («1 ₽», «договорная») |
| `pricing.auto_write_max_pct` | `25` | до скольких % выше скупки бот пишет сам |
| `pricing.notify_max_pct` | `40` | до скольких % присылает вам карточку |
| `pricing.hot_discount` | `0` | для 🔥: на сколько ₽ меньше цены продавца предлагать |
| `pricing.offer_round_to` | `500` | округление предложения вниз |
| `messaging.work_hours_start` / `_end` | `9` / `22` | часы автописем (по Москве) |
| `messaging.daily_message_limit` | `30` | максимум автописем в сутки |
| `messaging.templates` | 5 шаблонов | тексты первого сообщения, подстановки `{model}` `{memory}` `{offer}` |
| `replies.agree_words` / `refuse_words` | списки | слова согласия и отказа в ответах продавцов |

Токены и ID таблицы хранятся в `.env`. После их правки нужен перезапуск:
`./scripts/restart.sh` (или `Ctrl + C` и снова `./scripts/run.sh`).

## Если что-то не работает

**`command not found: python3.12`** — Python не установлен или Терминал открыт
до установки. Закройте Терминал (`⌘ Cmd + Q`), откройте снова. Если не
помогло, повторите шаг 2.

**`Permission denied` при запуске скрипта** — выполните
`chmod +x scripts/*.sh start.command` в папке проекта.

**`Бот уже запущен в другом окне или через автозапуск`** — бот уже работает.
Вторая копия не нужна. Остановить автозапуск: `./scripts/uninstall_autostart.sh`.

**В Telegram ничего не приходит**
- запустите `./venv/bin/python scripts/check_setup.py`: он скажет, что не так;
- проверьте, что нажали «Запустить» в своём боте;
- проверьте `TELEGRAM_CHAT_ID` в `.env` (шаг 5).

**«Доступ ограничен: проблема с IP»** в окне браузера — Авито решил, что с
вашего адреса слишком много запросов. Выключите VPN, пройдите капчу в окне
браузера (кнопка «Продолжить»). Если повторяется часто, увеличьте
`check_interval_sec` в `config.yaml`, например до 120.

**Ошибки Google Таблицы**
- `PERMISSION_DENIED` / `403` — таблица не открыта для `client_email` (шаг 6.3);
- `API has not been used` / `disabled` — не включены Sheets API и Drive API (шаг 6.2, п. 3);
- `WorksheetNotFound` — неверное `GOOGLE_SHEET_WORKSHEET`, впишите точное название вкладки;
- `нет файла ключа Google` — JSON-файл не в папке `credentials/` или называется иначе.

Если таблица временно недоступна, бот работает по последней загруженной версии
и пишет вам об ошибке один раз.

**Бот пишет «модель не определена» про нормальное объявление** — в заголовке
необычное написание. Логи с такими заголовками: `grep "Не определил" logs/bot.log`.
Пришлите примеры разработчику, разбор настраивается в `bot/pricing/model_parser.py`.

**Нормальные объявления отсеиваются как «запчасти»** — посмотрите `/stats`, какое
слово сработало, и добавьте фразу-исключение в `filters.stop_word_exceptions`.

**Где смотреть логи**: папка `logs/` — `bot.log` (всё), `errors.log` (только ошибки).

```bash
tail -n 100 ~/avito-iphone-bot/logs/bot.log
```

## Если Авито изменил сайт

Признаки: сообщение «🧩 Похоже, Авито изменил вёрстку», пустые поля в
карточках или ошибки «не нашёл кнопку «Написать»».

1. Остановите бота и запустите проверку:
   ```bash
   ./venv/bin/python scripts/check_avito.py
   ```
   Скрипт покажет, какие поля не прочитались, и список `data-marker` на странице.
   Это «имена» элементов, по которым бот их находит.
2. Откройте `bot/avito/selectors.py`. Для каждого поля там список вариантов,
   бот берёт первый найденный. Добавьте новый вариант в начало списка, например:
   ```python
   ITEM_DESCRIPTION = ["[data-marker='новое-имя']", "[data-marker='item-view/item-description']", ...]
   ```
3. Снова запустите `check_avito.py`, затем бота.

Если не разбираетесь в HTML, отправьте программисту вывод `check_avito.py` и
файл `data/layout_changed.png`: бот сохраняет туда скриншот проблемной страницы.

> **Важно.** Селекторы в `selectors.py` написаны по известной вёрстке Авито,
> но на живом сайте их пока не проверяли: при разработке Авито показывал
> страницу «Доступ ограничен». Обязательно сделайте шаг 9 и сутки пробного
> режима. Особенно проверьте отправку сообщения (кнопка «Написать»), переход
> в чат и чтение ответов в мессенджере: это первое, что может понадобиться
> подправить.

## Как устроен проект

```
avito-iphone-bot/
├── main.py                 # точка входа
├── config.yaml             # все настройки
├── .env                    # секреты (токены, ID таблицы) — создаётся из .env.example
├── prices_example.csv      # цены для проверки без Google Таблицы
├── start.command           # запуск двойным щелчком
├── bot/
│   ├── avito/
│   │   ├── browser.py      # браузер с постоянным профилем, распознавание капчи и входа
│   │   ├── selectors.py    # ВСЕ селекторы Авито
│   │   ├── search.py       # разбор выдачи
│   │   ├── listing.py      # разбор карточки и продавца
│   │   └── messenger.py    # отправка сообщений и чтение ответов
│   ├── pricing/
│   │   ├── sheet.py        # Google Таблица / CSV, кэш
│   │   ├── model_parser.py # модель и память из заголовка
│   │   └── decision.py     # зоны цен и предложение
│   ├── filters.py          # фильтры
│   ├── replies.py          # разбор ответов продавцов
│   ├── telegram/           # бот, кнопки, шаблоны уведомлений
│   ├── storage.py          # база SQLite (data/bot.db)
│   └── scheduler.py        # циклы, лимиты, рабочее время, пауза
├── scripts/                # установка, автозапуск, проверки
├── tests/                  # автотесты
├── data/                   # база и профиль браузера (создаётся само)
└── logs/                   # логи
```

Запустить автотесты (разбор моделей, ответов продавцов, фильтры, вся логика с заглушками):

```bash
./venv/bin/python -m pytest -q
```

**Начать с чистого листа** (бот забудет все просмотренные объявления и
диалоги): остановите бота и удалите файл `data/bot.db`. Вход в Авито
сохранится, он лежит в `data/browser_profile`.
